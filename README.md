# 中国建筑性能与环境标准

本仓库收录从中华人民共和国建筑标准资料中整理出的建筑性能、节能、室内环境、绿色建筑和碳排放相关内容，目标是提供可检索、可复用的 Markdown 正文和标准原始 PDF。

## 内容范围

| 标准 | 主题 | 当前状态 |
| --- | --- | --- |
| GB 50176-2016 | 民用建筑热工设计规范 | 已整理 Markdown 正文，已上传Wiki media |
| GB 50189-2015 | 公共建筑节能设计标准 | 已登记，原始资料为 PDF |
| GB 50352-2019 | 民用建筑设计统一标准 | 已登记，原始资料为 PDF |
| GB 50736-2012 | 民用建筑供暖、通风与空气调节设计规范 | 已登记，原始资料为 PDF |
| GB 55015-2021 | 建筑节能与可再生能源利用通用规范 | 已整理 Markdown 正文，已上传Wiki media |
| GB 55016-2021 | 建筑环境通用规范 | 已整理 Markdown 正文及附录A～D，并提供 [MediaWiki 文本](standards/GB/GB-55016-建筑环境通用规范/GB55016-2021.wikitxt) |
| GB 55031-2022 | 民用建筑通用规范 | 已整理 Markdown 正文，并提供 [MediaWiki 文本](standards/GB/GB-55031-民用建筑通用规范/GB55031-2022.wikitxt) |
| GB/T 18883-2022 | 室内空气质量标准 | 已登记，原始资料为 PDF |
| GB/T 50378 | 绿色建筑评价标准 | 已整理 2006、2014、2019 及 2024 局部修订版本Markdown 正文 |
| GB/T 51366-2019 | 建筑碳排放计算标准 | 已整理 Markdown 正文 |

- 完整字段、适用范围、关键内容和源文件映射见 [`standards/catalog.json`](standards/catalog.json)。

- 国家推荐性标准因其不存在法律效力，因此版权非公有，使用时应遵循合理使用原则，且无法上传Wiki media。

## 目录

```text
standards/
├── catalog.json       # 标准清单和关键内容索引
├── GB/                # GB 系列标准，每个标准独立目录
│   └── <标准号>/       # Markdown、原始 PDF 
└── GBT/               # GB/T 系列标准，每个标准独立目录
    └── <标准号>/       # Markdown、原始 PDF 
```
